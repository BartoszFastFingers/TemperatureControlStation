\doxysubsection{Opis szczegółowy}
Protokół UART dla komunikacji z PC/\+innym urządzeniem (komendy, odczyt temperatury, PWM). 

Plik definiuje struktury, komendy i funkcje obsługujące protokół UART:\+
\begin{DoxyItemize}
\item obsługa komend (PING, SET TEMP, START/\+\+STOP, PID),
\item wysyłanie danych pomiarowych,
\item obliczanie CRC8,
\item parsowanie odebranych bajtów.
\end{DoxyItemize}
