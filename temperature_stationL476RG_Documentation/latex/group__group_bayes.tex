\doxysubsection{Detailed Description}
Implement the naive gaussian Bayes estimator. The training must be done from scikit-\/learn.

The parameters can be easily generated from the scikit-\/learn object. Some examples are given in DSP/\+\+Testing/\+\+Pattern\+Generation/\+\+Bayes.\+py
