\doxysubsection{Opis szczegółowy}
Obsługa czujników temperatury z filtrem FIR (SMA) dla mikrokontrolerów STM32. 

Moduł umożliwia:\+
\begin{DoxyItemize}
\item inicjalizację czujników ADC,
\item odczyt napięcia i temperatury,
\item obliczanie średniej temperatury z filtracją cyfrową (SMA/\+\+FIR).
\end{DoxyItemize}
