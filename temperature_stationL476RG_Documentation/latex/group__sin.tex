\doxysubsubsection{Detailed Description}
Computes the trigonometric sine function using a combination of table lookup and linear interpolation. There are separate functions for Q15, Q31, and floating-\/point data types. The input to the floating-\/point version is in radians while the fixed-\/point Q15 and Q31 have a scaled input with the range \+[0 +0.\+9999]\+ mapping to \+[0 2\texorpdfstring{$\ast$}{*}pi). The fixed-\/point range is chosen so that a value of 2\texorpdfstring{$\ast$}{*}pi wraps around to 0.

The implementation is based on table lookup using 512 values together with linear interpolation. The steps used are:\+
\begin{DoxyEnumerate}
\item Calculation of the nearest integer table index
\item Compute the fractional portion (fract) of the table index.
\item The final result equals {\ttfamily (1.\+0f-\/fract)\texorpdfstring{$\ast$}{*}a + fract\texorpdfstring{$\ast$}{*}b;}
\end{DoxyEnumerate}

where

   b = Table[index];
   c = Table[index+1];
\end{DoxyPre}
