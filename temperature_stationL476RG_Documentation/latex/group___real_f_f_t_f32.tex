\begin{DoxyParagraph}{Description}
The parameter {\ttfamily fft\+Len} specifies the length of RFFT/\+\+CIFFT process. Supported FFT Lengths are 32, 64, 128, 256, 512, 1024, 2048, 4096.
\end{DoxyParagraph}
\begin{DoxyParagraph}{}
This Function also initializes Twiddle factor table pointer and Bit reversal table pointer.
\end{DoxyParagraph}
\begin{DoxyParagraph}{}
This function should be used only if you don\textquotesingle{}t know the FFT sizes that you\textquotesingle{}ll need at build time. The use of this function will prevent the linker from removing the FFT tables that are not needed and the library code size will be bigger than needed.
\end{DoxyParagraph}
\begin{DoxyParagraph}{}
If you use CMSIS-\/\+DSP as a static library, and if you know the FFT sizes that you need at build time, then it is better to use the initialization functions defined for each FFT size. 
\end{DoxyParagraph}
