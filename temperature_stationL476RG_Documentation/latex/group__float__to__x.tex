If the input float values are very big (2\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}32) then the function won\textquotesingle{}t be able to saturate to the right values. If you expect very big float values in the input array then you should force those values to +1 or -\/1 before calling this function. For reasonable float values (\texorpdfstring{$<$}{<} 2\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}32), the function will saturate correctly. 
\end{DoxyNote}
